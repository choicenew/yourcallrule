# 社区高频黑名单规则 (Community Feed)

本目录（`community_feed/`）为独立整理的骚扰拦截规则库。所有数据均按国家/地区（E.164 国际代码前缀）进行分拣隔离，使用者可根据需求单独拉取对应国家或通用的黑名单规则。

---

### 一、 目录划分与使用说明

各类规则数据按照国家/地区代码独立保存在不同子文件夹中：

- `community_feed/GLOBAL/`：全球通用全量规则与 24 小时热点爆发规则
  - `full_block.json`：全球全量拦截规则
  - `hot_block.json`：近 24h 爆发热点拦截规则
- `community_feed/US/`：美国 / 加拿大 (`+1`) 专属拦截规则
- `community_feed/FR/`：法国 (`+33`) 专属拦截规则
- `community_feed/IN/`：印度 (`+91`) 专属拦截规则
- `community_feed/DE/`：德国 (`+49`) 专属拦截规则
- `community_feed/CN/`：中国 (`+86`) 专属拦截规则
