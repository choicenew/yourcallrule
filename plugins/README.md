## English

### Plugin System & Community Development

The **YourCallYourRule** plugin system allows users to identify unknown numbers by extracting phone lookup information from online sources.

> **Important Notice**:  
> Active plugin development, templates, and community-contributed plugins are now maintained in the dedicated developer repository:  
> **[https://github.com/ngodeel/yourcallrule](https://github.com/ngodeel/yourcallrule)**  
> (`git clone https://github.com/ngodeel/yourcallrule.git`)

For the latest plugin updates, template files, or to submit your own custom plugins, please visit the new repository above.
